## 2024-05-18 - Offloading heavy FFI (opencv_dart) image processing from UI thread
**Learning:** In Dart/Flutter apps using `opencv_dart`, synchronous FFI calls (like `cv.imdecode`, `cv.convertScaleAbs`, `cv.imwrite`) block the main UI thread. Even simple image editor confirmations can cause significant UI jank or ANRs because `cv.Mat` operations are computationally intensive.
**Action:** Always wrap `opencv_dart` operations in an `Isolate.run()` to offload to a background thread. Extract UI state (like `GlobalKey` properties) and platform channel calls (`getTemporaryDirectory`) to the main thread *before* spawning the isolate, as these cannot cross isolate boundaries safely. Ensure unmanaged native objects (`cv.Mat`) are disposed properly inside the isolate's `finally` block to avoid memory leaks.
